What syncs, and what stays separate?

Saved settings, language, theme, layout, and open session tabs sync between these two addresses within the same browser profile. Hub’s previous preference values are backed up before import. Draft composers, prompt history, credentials, and server registrations stay local. This is not cross-device account sync. The live mobile UI keeps its responsive tab drawer.

The existing owner-only sign-in remains in place. No server restart is needed. If OpenCode sign-in has expired or that address is unreachable, Hub can still open with its local settings.
